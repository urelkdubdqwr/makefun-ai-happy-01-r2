## Details

A deterministic generative picture (pure Python 3 standard library) of a
chubby orange cat at its surprise birthday party: party hat, eyes squeezed
shut, mouth wide open mid-laugh, tears of joy, both paws thrown up, with
balloons, confetti and a rainbow behind it. Custom SDF rasterizer and a
hand-rolled PNG encoder — no dependencies, no network, no randomness
beyond a fixed seed.

Run: `python3 main.py` writes the picture to `/output/entry.png`
(1024x1024 PNG, byte-identical on every run; set `ENTRY_OUT` to override
the path locally).
